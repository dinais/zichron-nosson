# זכרון נתן (ע״ר)

אתר סטטי לעמותת זכרון נתן.

## העלאה ל-GitHub Pages

1. ב-GitHub: **New repository**, שם לדוגמה `zichron-nosson`, סימון **Public**.
2. **Add file → Upload files**, גרירת `index.html` (ואת קובץ זה), ו-**Commit changes**.
3. **Settings → Pages → Build and deployment**: Source = *Deploy from a branch*, Branch = `main`, תיקייה `/ (root)`, ו-**Save**.
4. אחרי דקה-שתיים האתר יעלה בכתובת:
   `https://USERNAME.github.io/zichron-nosson/`

## עריכה

כל הטקסטים שמסומנים בהערות `<!-- ... -->` בקובץ `index.html` הם תוכן זמני שיש להחליף.
